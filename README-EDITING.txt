SADAFRONIA HOMEPAGE V1

האתר נבנה מחדש בתיקיות נקיות:

index.html                — מבנה ותוכן עמוד הבית
assets/css/site.css       — כל העיצוב והרספונסיביות
assets/js/site.js         — תפריט, אנימציות, וידאו, חיפוש וטופס
assets/images/            — תמונות האתר
assets/video/             — סרטוני הירו לדסקטופ ולמובייל

כלל עבודה:
1. תוכן וטקסט משנים ב-index.html.
2. צבעים ראשיים משנים בתחילת site.css תחת :root.
3. תמונה מחליפים בלי לשנות קוד, כל עוד שומרים על אותו שם קובץ.
4. לפני העלאת עמוד חדש מעתיקים את מבנה ה-header וה-footer כדי לשמור על אחידות.
